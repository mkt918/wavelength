# ウェーブレングス（協力モード）

ボードゲーム「ウェーブレングス」の協力モードを、1台の端末を回して遊ぶ Web アプリにしたもの。
授業・レクで生徒がスマホで使う前提。サーバー無し・ビルド無し・完全オフラインで動く。

**公開URL: https://mkt918.github.io/wavelength/**

- 対戦モード・左右当てフェイズは作らない（協力モードのみ）
- ものさしカード（100組）と達成度メッセージは原作を流用せず、すべて独自文
- ライトテーマのみ（ダークテーマは作らない）
- ルールはプリセット（公式／かんたん／むずかしい）に加えて、スライダー・ボタンで細かく変更できる

## ことば（用語）

| ことば | 意味 |
|---|---|
| ものさし | 両端に言葉が書かれた1本の線。例：「熱い」⟷「冷たい」 |
| ターゲット | ものさしの上にある色つきの正解ゾーン。出題者にだけ見える |
| お題 | 出題者がターゲットの位置を伝えるために言う「ひとこと」 |
| ダイヤル | チームが動かす針 |

※ 2026-09-29 に整理した。以前は「ヒント」（出題者の言葉）と「お題」（ものさし）と呼んでいたが、
ユーザーレビューで混乱が多かったため入れ替えた。コード内部の名前（`hintOnScreen`, `pHint` など）は保存データとの互換のためそのまま。

## 遊び方

1. **設定画面** でプレイヤー名（任意）とルールを決めて「はじめる」
   - プリセット: 公式 / かんたん / むずかしい。「くわしく設定する」でスライダー・トグルから個別に変更できる（変更すると「カスタム」表示になる）
   - はじめて開いたときは、遊び方の説明（5ステップ）が自動で出る。あとから「はじめての人へ：遊び方」ボタンでも見られる
2. **出題者に端末を渡す** → 出題者はものさしの表裏どちらかを選び、ターゲットの位置を見てお題を考える（「お題の考え方・見本を見る」で見本が出る）
3. お題を入力（または口頭で伝えて）「画面を隠す」
4. **チームに端末を渡す** → ダイヤルをドラッグかスライダーで合わせて「決定」
5. ターゲットが公開され得点。中央に当たるとカードが1枚追加される（設定でオフにできる）
6. カードがなくなったら終了。合計点と達成度メッセージが出る

ゲーム中の出題者・チーム・結果の画面には「？」ボタンがあり、その画面でやることを確認できる。

得点ゾーンは 5 分割で、既定は `2-3-4-3-2` 点（中央 4 点）。ゾーン外は 0 点。
くわしいルール・お題の出し方のコツは [rules.html](rules.html) を参照。

進行中のゲームは localStorage に保存されるので、うっかりリロードしても同じ画面に戻る。上部バーの「中断」で最初に戻れる。

## 変更できるルール設定

| 項目 | 範囲 | 既定（公式） |
|---|---|---|
| ラウンド数（カード枚数） | 3〜15 | 7 |
| ゾーンの広さ（1ゾーンの角度） | 4°〜14° | 7° |
| 中央ゾーンの点数 | 3 / 4 | 4 |
| 外側ゾーンの点数 | 1 / 2 | 2 |
| 中央に当てたらカード追加 | on/off | on |
| お題を画面に表示する | on/off | on |

## ものさしの追加

`data/prompts.js` を直接編集する。1枚のカードに表（a）と裏（b）の2面がある。

```js
{
  a: { left: '熱い', right: '冷たい', ex: ['サウナ', 'ぬるま湯', 'かき氷'] },
  b: { left: '不安定', right: '安定', ex: ['積み上げたジェンガ', '自転車', 'ピラミッド'] },
},
```

- `left` がダイヤルの左端（0°）、`right` が右端（180°）
- `ex` は出題者向けの**お題の見本**（左寄り／まんなか／右寄りの順に3つ）。ターゲットの位置とは無関係に、いつも同じ3つを見せる
- 原作カードの文面は使わず、独自に作成すること
- 追加したら `node js/tests.js` で、全面に `ex` が3つあること・ペアの重複がないことを確認できる

## ローカルで動かす

`index.html` をダブルクリックで開くだけで動く（Web フォント・外部ライブラリ無し、完全オフライン）。
テストは `tests.html` を開くか、次を実行する。

```bash
node js/tests.js
```

## ファイル構成

```
index.html          画面（7画面を1枚に。data-screen で切替）
rules.html          ことばの説明・遊び方・お題の出し方のコツ・設定項目の解説
tests.html          ブラウザで開くだけで走る自己検証
css/
  tokens.css        デザイントークン（hallmark / Coral / ライトのみ）
  style.css         画面のスタイル
js/
  game-logic.js     ルールエンジン（純粋関数、DOM/localStorage/Math.random 非依存）
  dial.js           半円ダイヤルの SVG 描画・ドラッグ/キーボード操作
  app.js            状態機械・DOM 制御・localStorage・チュートリアル・「？」ヘルプ
  sound.js          結果発表の効果音・振動（WebAudio で合成、外部音源なし）
  tests.js          game-logic とものさしデータのテスト（ブラウザ / node 両対応）
data/
  prompts.js        ものさしカード（50枚・100組、見本つき）
.hallmark/log.json  hallmark の履歴
```

ルールを変えるときは `js/game-logic.js` だけを触る（純粋関数、乱数は引数 `rng` で受け取る）。
変更したら `js/tests.js` にテストを足し、`node js/tests.js` か `tests.html` で全件 PASS を確認する。
色・フォントは `css/tokens.css` の変数経由のみで、生の色値をハードコードしない。
